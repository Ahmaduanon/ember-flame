Ember 0.2

Building surveys. Sensor observations. Incident review. Gravity & flame experiments.

  1. Extract the entire project ZIP on a desktop computer.
  2. Install Node.js 22.13 or newer if needed.
  3. Windows: open START-LAB.cmd. macOS: open Start-Lab.command, or run sh start-lab.sh. Linux: run sh start-lab.sh.
  4. Keep that window running and open http://localhost:3000.
  5. Choose Buildings & alerts → Add a room. Add photos and manual observations, or try a labeled sensor demonstration.

No GitHub account, npm installation or build is needed for the included prebuilt app. The desktop app cannot be launched directly from iPhone Files.

AI setup is separate. Install a local Ollama vision model following AI-SETUP.md. Manual observations and demonstrations work before AI setup.
